Internal Tooling Suite — Module 01: Doc-Sync Engine

Markdown (repos) → GitHub Actions → Centralized Tooling Suite → Confluence REST API

Module 01: Doc-Sync Engine

  • • Discovers Markdown via per-repo .doc-sync.yml
  • • Converts to Confluence Storage Format (XHTML)
  • • Hash + version-aware conflict detection
  • • Idempotent, dry-run capable, safe retries

Security & Auth

  • • GitHub Actions OIDC + encrypted org secrets
  • • Least-privilege Confluence bot account (PAT/OAuth2)
  • • No secrets ever committed to caller repos
  • • Quarterly credential rotation

Roadmap — Future Modules

  • • /tools/xray-scan — JFrog CLI + Xray security scans
  • • /tools/gh-actions-wrappers — reusable composite actions
  • • Shared /tools/common lib (auth, logging, config loader)
  • • Single CLI entrypoint: `tools <subcommand>`
